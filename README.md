## 📖 About

Budget Calculator is a smart CLI tool, written in C, that helps you organize your monthly expenses and manage your budget, all through a conversational interface. Forget the spreadsheets—just run, chat, and gain insights!

---

## ✨ Features

- 🗣️ Friendly CLI prompts that guide you step by step
- 💰 Income and expense tracking
- 📊 Categorize expenses for clarity
- 📝 Save reports to text files
- 🔔 Alerts when you near budget limits
- 💽 Lightweight and fast

---

## 🚀 Getting Started

### Prerequisites

- C compiler (GCC/MinGW/Clang/MSVC)

### Run Locally

```bash
git clone https://github.com/dipan313/Budget-Calculator_Expense-tracker-.git
cd Budget-Calculator_Expense-tracker-
gcc Budgetcalculator.c -o BudgetCalculator
./BudgetCalculator    # Or run Budgetcalculator.exe on Windows
```

---

## 💡 Usage

Just launch the program and follow the on-screen prompts:

1. Enter your monthly income and set your budget
2. Add expenses as they occur
3. View categorized reports
4. Track savings and leftover budget

*Sample session:*

```
Welcome to Budget Calculator!

Enter your monthly income: 40000
Would you like to add an expense? (y/n): y
Expense name: Internet
Amount: 999
Category: Utilities
Remaining budget: 39001
```
